# videoautocuter
VideoAutoCuter is a simple, automated tool for cutting footage from gaming sessions. It identifies highlights, helps prepare vertical clips, and allows for the correction of subtitles. To use it: select an MP4 file, specify the number of highlights, choose the language and subtitle settings, click "Find Highlights," select the desired segments, and click "Export Selected." A history of your processed files is available at the top of the window.
