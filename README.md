# videoautocuter
VideoAutoCuter — простой автонарезчик длинных игровых видео. Находит интересные моменты, помогает подготовить вертикальные клипы и исправить субтитры. Управление: выберите MP4, задайте число моментов, язык и субтитры, нажмите «Найти моменты», отметьте фрагменты и нажмите «Экспортировать выбранные». Двойной щелчок по моменту запускает предпросмотр.
